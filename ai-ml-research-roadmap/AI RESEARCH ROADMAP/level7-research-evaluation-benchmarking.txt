Level 7 · Reinforcement Learning, Search & Test-Time Reasoning

Phase: Reasoning, Benchmarks & Rigor
Suggested duration: 13 sessions (~3 weeks)
Prerequisites: Level 6 (Generative Modeling & Probabilistic Machine Learning)
Scope: Master reinforcement learning, planning, and test-time reasoning in AI research: Markov Decision Processes (MDPs), policy optimization (PPO, SAC), search algorithms (MCTS, Tree-of-Thoughts), Process Reward Models (PRMs), and test-time compute scaling laws.

M7.1 · Markov Decision Processes, Dynamic Programming & Bellman Optimality — (sessions: 2)
Session 1 · Mathematical Foundations of Reinforcement Learning
- Formulate the reinforcement learning problem as a Markov Decision Process (MDP): state space S, action space A, transition probability P, reward function R, and discount factor gamma.
- Formalize policies pi(a|s), state-value functions V^pi(s), and action-value functions Q^pi(s, a) under infinite-horizon discounted return objectives.
- Derive the Bellman Expectation Equations for V^pi and Q^pi by unrolling the recursive definition of expected discounted return.
Session 2 · Bellman Optimality & Contraction Mappings
- State and prove the Bellman Contraction Mapping theorem under the L-infinity norm, establishing the existence and uniqueness of the optimal value function Q*.
- Implement exact dynamic programming algorithms: Policy Iteration (alternating policy evaluation and policy improvement) and Value Iteration.
- Analyze the curse of dimensionality in continuous state and action spaces, motivating deep parametric function approximation.
Mental model: The Bellman equation is a recursive consistency constraint; dynamic programming contracts arbitrary value guesses toward the true optimal policy.
Try: Implement Value Iteration in Python for a discrete gridworld MDP, verify contraction mapping convergence rates, and extract the optimal deterministic policy.
Outcome: Formulate sequential decision-making problems as MDPs and derive the fundamental convergence proofs of dynamic programming.

M7.2 · Deep Q-Networks & Value Function Approximation Stability — (sessions: 2)
Session 1 · Q-Learning with Deep Neural Networks
- Approximate action-value functions using deep neural networks Q_theta(s, a) and formulate the temporal difference (TD) loss objective.
- Identify the root causes of instability in non-linear value approximation: non-stationary target distributions, correlated data streams, and policy oscillations.
- Implement the core Deep Q-Network (DQN) stabilizing mechanisms: experience replay buffer sampling and decoupled frozen target networks Q_target.
Session 2 · Advanced Value Function Enhancements
- Mitigate overestimation bias in action-value updates using Double DQN (DDQN), decoupling action selection from value evaluation.
- Implement Dueling DQN architectures, decomposing Q(s, a) into independent state value V(s) and state-dependent action advantage A(s, a) streams.
- Master Prioritized Experience Replay (PER), sampling historical transitions according to TD-error magnitudes with importance-sampling correction weights.
Mental model: Double DQN prevents maximization bias: the main network nominates the best action, while the target network calculates its honest value.
Try: Implement a Deep Q-Network from scratch in PyTorch with experience replay and target networks, training it to solve the CartPole-v1 benchmark environment.
Outcome: Build stable deep Q-learning architectures and eliminate maximization bias using Double DQN and dueling streams.

M7.3 · Policy Gradients, Trust Region Policy Optimization (TRPO) & PPO — (sessions: 2)
Session 1 · The Policy Gradient Theorem & REINFORCE
- Derive the Policy Gradient Theorem analytically: \nabla_theta J(theta) = E_{tau ~ pi_theta}[\sum_t \nabla_theta log pi_theta(a_t|s_t) G_t].
- Implement the REINFORCE algorithm with baseline subtraction to reduce gradient variance without introducing estimator bias.
- Formulate Generalized Advantage Estimation (GAE), balancing the bias-variance trade-off in temporal difference returns using the exponential decay factor lambda.
Session 2 · Trust Region Methods & Proximal Policy Optimization (PPO)
- Understand policy collapse: small parameter updates in neural policies can cause catastrophic performance degradation from which the agent cannot recover.
- Formulate the Trust Region Policy Optimization (TRPO) objective enforcing a Kullback-Leibler (KL) divergence constraint D_KL(pi_old || pi) <= delta.
- Implement Proximal Policy Optimization (PPO): the clipped surrogate objective L_CLIP(theta) bounding policy probability ratios without expensive second-order Hessian computation.
Mental model: PPO's clipped objective is an insurance policy: it forbids the policy from changing too dramatically in a single update step.
Try: Implement the PPO clipped objective function in PyTorch, verify that gradient updates are zeroed out when probability ratios exceed 1 + epsilon or 1 - epsilon.
Outcome: Derive the policy gradient theorem, implement Generalized Advantage Estimation, and master Proximal Policy Optimization.

M7.4 · Test-Time Reasoning: Chain-of-Thought, Tree-of-Thoughts & MCTS Search — (sessions: 2)
Session 1 · Circuit Complexity of Reasoning & Chain-of-Thought
- Analyze the computational expressivity of autoregressive Transformers: constant-depth circuit limitations on complex multi-step reasoning tasks.
- Formalize Chain-of-Thought (CoT) prompting as allocating additional dynamic runtime token steps, increasing effective computational circuit depth.
- Differentiate between zero-shot CoT ("Let's think step by step"), few-shot exemplar demonstrations, and self-consistency voting across multiple sampled traces.
Session 2 · Structured Search Over Latent Thought Spaces
- Formulate reasoning as explicit search over a state space of intermediate thoughts: the Tree of Thoughts (ToT) framework.
- Implement graph search heuristics over thought trees: breadth-first search (BFS), depth-first search (DFS) with backtracking, and beam search.
- Master Monte Carlo Tree Search (MCTS) for language model reasoning: Selection (PUCT formula), Expansion, Rollout/Evaluation, and Backpropagation.
Mental model: Autoregressive decoding is a single greedy walk through thought space; MCTS explores a branching tree of alternative deduction paths.
Try: Implement a Tree of Thoughts search controller in Python using an LLM API, solving a complex mathematical puzzle via systematic branching and pruning.
Outcome: Formalize test-time reasoning as computational search, implement Tree-of-Thoughts, and integrate Monte Carlo Tree Search.

M7.5 · Process vs. Outcome Supervision: Training Process Reward Models (PRMs) — (sessions: 2)
Session 1 · The Limits of Outcome Reward Models (ORMs)
- Analyze Outcome Reward Models (ORMs): assigning a single binary scalar reward at the conclusion of a multi-step reasoning trajectory.
- Identify the credit assignment problem in ORMs: intermediate logical errors receive positive credit if the final answer is accidentally correct (false positives).
- Understand step-level reward hacking where models generate degenerate or repetitive intermediate derivations to satisfy coarse outcome signals.
Session 2 · Process Reward Models & Step-Level Verification
- Formulate Process Reward Models (PRMs): predicting the step-by-step correctness probability r_t \in [0, 1] for every individual deduction step.
- Implement step-level synthetic data collection protocols: automated verification rollouts, Monte Carlo value estimation, and active learning annotation.
- Evaluate search efficiency: compare Best-of-N selection and guided beam search steered by PRMs versus standard ORMs on mathematical reasoning benchmarks (MATH, GSM8K).
Mental model: An ORM only checks the final destination; a PRM acts as an experienced mathematician grading every individual step on the chalkboard.
Try: Train a step-level verification classifier on mathematical solutions, score multi-step traces, and use PRM scores to guide a beam search decoder.
Outcome: Implement Process Reward Models from scratch, solve credit assignment in multi-step reasoning, and steer test-time search.

M7.6 · Capstone Project: Policy Optimization Benchmark & Guided Tree Search Engine — (sessions: 3)
Session 1 · Reinforcement Learning Core & Reasoning Search Architecture
- Implement a modular, vectorized implementation of Proximal Policy Optimization (PPO) in PyTorch with Generalized Advantage Estimation.
- Construct a test-time search controller combining an autoregressive policy model with a step-level Process Reward Model (PRM).
- Implement the Upper Confidence Bound for Trees (PUCT) algorithm to balance exploration and exploitation across intermediate reasoning branches.
Session 2 · Test-Time Scaling Law Profiling & Empirical Defense
- Benchmark reasoning performance across test-time compute budgets: evaluate accuracy as a function of search rollout samples and tree expansions.
- Plot empirical test-time compute scaling curves comparing greedy decoding, Best-of-N sampling, and MCTS tree search.
- Author a research report documenting empirical findings, ablation studies on tree search parameters, and comparative reasoning accuracy.
Mental model: Test-time compute scaling demonstrates that additional inference compute can substitute for orders of magnitude more pre-training parameters.
Try: Run the guided MCTS search engine across 50 challenging reasoning problems, and plot the accuracy curve as search budget increases from 1 to 64 samples.
Outcome: Build state-of-the-art reinforcement learning and guided tree-search algorithms and analyze test-time compute scaling laws empirically.
