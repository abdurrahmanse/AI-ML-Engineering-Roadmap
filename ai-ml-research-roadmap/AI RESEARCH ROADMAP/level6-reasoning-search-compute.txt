Level 6 · Sequence Models, Graph Neural Networks & Transformers

Phase: Model Architectures & Paradigms
Suggested duration: 13 sessions (~3 weeks)
Prerequisites: Level 5 (Classical Machine Learning & Deep Learning Paradigms)
Scope: Investigate modern representation architectures across complex relational and sequential data: self-attention mechanisms, Vision Transformers (ViT) and Swin Transformers, Graph Neural Networks (GCN, GAT, GraphSAGE) for cybersecurity threat graphs (botnet detection, binary function call graphs) and molecular interactions, and linear attention/state space models (Mamba, S4) for long-sequence genomic and network telemetry modeling.

M6.1 · Self-Attention Mechanics & the Modern Transformer — (sessions: 2)
Session 1 · Scaled Dot-Product & Multi-Head Self-Attention
- Derive scaled dot-product attention from first principles: query, key, value matrix projections, softmax scaling factors, and attention dispersion.
- Implement multi-head attention (MHA), Multi-Query Attention (MQA), and Grouped-Query Attention (GQA), analyzing KV-cache memory reductions.
- Compare positional encodings: absolute sinusoidal encodings, learned positional embeddings, ALiBi (Attention with Linear Biases), and Rotary Position Embeddings (RoPE).
Session 2 · Computational Efficiency & Hardware-Aware Attention (FlashAttention)
- Analyze the quadratic computational and memory complexity O(N^2) of standard attention with respect to sequence length N.
- Master the IO-awareness principles of FlashAttention (Dao et al.): tiling matrices across fast GPU SRAM to avoid high-bandwidth memory (HBM) memory bandwidth bottlenecks.
- Implement causal attention masking, padding masks, and document packing for efficient variable-length sequence batching.
Mental model: Standard attention is memory-bandwidth bound, not compute-bound; FlashAttention reorganizes matrix multiplications to fit within fast on-chip GPU SRAM.
Try: Implement scaled dot-product attention in PyTorch from scratch, verify output equivalence with torch.nn.functional.scaled_dot_product_attention, and benchmark memory scaling.
Outcome: Build, optimize, and mathematically analyze modern attention mechanisms and hardware-aware Transformer layers.

M6.2 · Vision Transformers & Hierarchical Attention in Medical Imaging — (sessions: 2)
Session 1 · Vision Transformers (ViT) & Patch Tokenization
- Transition Transformers to 2D spatial domains: non-overlapping patch extraction, linear projection to 1D patch tokens, and prependable [CLS] tokens.
- Analyze inductive bias differences: why ViTs require large-scale pre-training compared to CNNs due to the absence of translation equivariance and locality biases.
- Implement attention map rollouts and Grad-CAM for Vision Transformers to visualize clinical attention on thoracic lesions.
Session 2 · Hierarchical & Shifted Window Transformers (Swin Transformer)
- Architect the Swin Transformer: hierarchical feature representation via patch merging and shifted local window self-attention with linear computational complexity.
- Apply Swin-UNETR and hybrid Transformer-CNN architectures to 3D volumetric medical segmentation and gigapixel whole-slide histopathology images (WSI).
- Analyze multi-scale attention mechanisms for resolving both fine-grained cellular features and global organ-level context simultaneously.
Mental model: ViTs treat images as sentences of visual words; Swin Transformers reintroduce hierarchical spatial pyramids while maintaining attention flexibility.
Try: Implement a patch embedding module in PyTorch, construct a Vision Transformer backbone, and visualize attention weights across a medical chest X-ray image.
Outcome: Apply Vision Transformers and hierarchical attention models to medical radiological imaging and high-resolution spatial data.

M6.3 · Graph Neural Networks: Message Passing, GCN & GAT — (sessions: 2)
Session 1 · The Message Passing Neural Network (MPNN) Framework
- Formalize graph-structured data: node feature matrices, edge index adjacency lists, and edge attribute tensors using PyTorch Geometric (PyG).
- Formulate the general Message Passing framework: neighborhood message aggregation, message transformation, and node state update functions.
- Analyze the theoretical expressive limits of message-passing GNNs: the 1-dimensional Weisfeiler-Lehman (1-WL) graph isomorphism test.
Session 2 · Spectral & Spatial GNNs (GCN, GAT & GraphSAGE)
- Implement Graph Convolutional Networks (GCN) via localized first-order spectral approximations of graph Laplacians.
- Implement Graph Attention Networks (GAT): calculating learnable anisotropic attention coefficients between neighboring nodes.
- Apply GraphSAGE (Sample and Aggregate) for inductive learning on large-scale evolving graphs using neighborhood sub-sampling.
Mental model: A GNN is a generalized convolution where each node dynamically aggregates information from its arbitrary topological neighborhood.
Try: Build a 2-layer Graph Attention Network (GAT) with multi-head neighborhood attention in PyTorch Geometric, training it on a node classification benchmark.
Outcome: Master the Message Passing paradigm and implement state-of-the-art spatial and attention-based Graph Neural Networks.

M6.4 · Graph Neural Networks for Cybersecurity & Complex Threat Topologies — (sessions: 2)
Session 1 · Network Provenance & Botnet Detection Graphs
- Represent cybersecurity telemetry as directed property graphs: network communication graphs (IP to IP), host authentication graphs, and system provenance logs.
- Detect coordinated botnet command-and-control (C2) topologies using GNN node and edge classification on large-scale network flow graphs.
- Handle dynamic and temporal graphs: incorporating edge timestamps, packet volumes, and protocol features into continuous-time dynamic graph networks (TGN).
Session 2 · Binary Disassembly & Control Flow Graphs (CFG)
- Disassemble compiled malicious binaries into Control Flow Graphs (CFG) and Abstract Syntax Trees (AST) using Ghidra or radare2.
- Train Graph Convolutional Networks on function-level CFGs to classify malware families and detect obfuscated zero-day exploit variants.
- Mitigate graph oversmoothing and oversquashing when message passing traverses deep multi-hop dependency chains in large computer networks.
Mental model: Cyber threats operate across distributed networks; graph neural networks capture relational attack topologies invisible to isolated log analyzers.
Try: Construct an enterprise network communication graph from network flow logs in PyG, train a GNN to detect compromised lateral-movement host nodes.
Outcome: Formulate cybersecurity threat detection problems as graph neural network tasks, modeling network flow graphs and malware binary control flow topologies.

M6.5 · State Space Models & Long-Sequence Architectures (Mamba & S4) — (sessions: 2)
Session 1 · Continuous State Spaces & Structured S4
- Analyze the quadratic bottleneck of Transformers when processing ultra-long sequences (e.g., millions of base pairs in genomics or continuous network traffic).
- Formalize linear continuous-time State Space Models (SSMs): mapping continuous 1D inputs to outputs through latent continuous hidden states.
- Discretize continuous state spaces using the bilinear transform and the HiPPO (High-order Polynomial Projection Operators) framework for optimal memory initialization.
Session 2 · Selective State Spaces: The Mamba Architecture
- Implement Mamba (Gu & Dao): introducing input-dependent, selective parameters into the state space matrices (B, C, and step size Delta).
- Master the hardware-aware selective scan algorithm: computing linear recurrent updates via an associative parallel scan directly in GPU SRAM.
- Evaluate Mamba on long-context sequence benchmarks: comparing token throughput, memory footprint, and sequence extrapolation against FlashAttention Transformers.
Mental model: Mamba achieves the parallel training efficiency of Transformers and the constant-memory O(1) inference speed of recurrent neural networks.
Try: Implement a 1D selective state space layer in PyTorch, compare training wall-clock time and memory consumption against standard attention across sequence length N=16,384.
Outcome: Apply sub-quadratic linear attention and selective state space models (Mamba) to long-sequence scientific and telemetry data.

M6.6 · Capstone Project: Relational Graph & Long-Sequence Research Model Implementation — (sessions: 3)
Session 1 · Research Model Architecture & Pipeline Engineering
- Select either a cybersecurity graph problem (botnet/lateral movement detection on network provenance graphs) or a medical long-sequence task (genomic/ECG sequence modeling).
- Build a custom research architecture integrating advanced graph attention (GAT with edge attributes) or selective state space blocks (Mamba/S4).
- Construct a high-performance data pipeline handling dynamic graph batching or million-token continuous sequences with zero memory thrashing.
Session 2 · Rigorous Empirical Benchmarking & Ablation Study
- Benchmark the proposed model against standard Transformer (MHA/FlashAttention) and classical baseline baselines.
- Execute ablation experiments: systematically isolate the contribution of attention mechanisms, state-space selectivity, and edge feature aggregations.
- Measure and report computational efficiency metrics: peak VRAM scaling, training FLOPs, inference latency per token, and classification AUROC.
Mental model: Implementing modern non-standard architectures like GNNs or State Space Models demonstrates deep technical mastery in high-impact research areas.
Try: Run the full comparative pipeline, logging training curves, memory consumption profiles, and statistical significance tests comparing against baselines.
Outcome: Complete a publication-ready implementation and empirical evaluation of an advanced Graph Neural Network or State Space Model.
